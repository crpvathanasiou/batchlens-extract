## Corrections

1. **Comparable candidate order.** `_interpretation_key` contains optional values such as `lexical_term_id`, IDs, and qualifiers. `_candidate_sort_key` currently returns the raw tuple, so two distinct candidates sharing an earlier prefix but having `None` versus `str` can raise `TypeError` at `sorted(groups, ...)`. Give every optional value a deterministic comparable sort representation without altering grouping equality, source namespaces, or candidate content. Test at least two same-span FDA/EMA candidates with absent versus present `lexical_term_id` and reversed discovery/shard order. Both must survive in stable order with valid `BlockRecord` evidence.

2. **Actual bounded ingestion and block loading.** `_ingest_discoveries` retains `per_block: dict[str, int]` for the entire document, growing with distinct block IDs. Move per-block counting to bounded/disk-backed spool logic, or enforce the per-block limit at bounded retrieval without keeping an all-block dictionary. `_load_block_hits` calls `fetchall()` before checking `result_buffer_records`; fetch at most `limit + 1` rows and fail before materializing a larger block. Do not silently truncate, change the configured limit, or add a generic storage framework. Avoid `PRAGMA temp_store=MEMORY` if it allows a large SQLite sort/index to escape the intended bounded-memory design. Add focused overflow and many-distinct-block tests that demonstrate the bound by behavior, not just by checking a helper name.

3. **No completed coverage for unmatched spooled hits.** The final block replay currently can omit a block referenced by a valid spooled discovery and still set successful `coverage`, because only emitted blocks are processed. Track spool consumption on disk and, after a complete replay, fail with a bounded structured error if any hit belonged to no emitted block. Preserve the upstream L07/L03 identity check; require an actually pinned L07 identity for production aggregation rather than allowing `expected_source_identity=None` to act as a silent bypass. Synthetic fixtures may supply an explicit stable identity. Test a valid discovery for an absent replay block, including the case of an empty replay, and verify no completed coverage. Keep emitted records provisional until the end; do not publish a result in L08.

4. **Cleanup and upstream iterator lifecycle.** `_run` sets `coverage` before closing/deleting the spool and currently swallows connection/temporary-directory cleanup errors. Do not expose completed coverage when cleanup failed. Handle partial `_open_spool` initialization failures by closing an already-open connection. If ingestion stops early on an error (for example an unexpected unit or lookup mismatch), close a closable upstream L07 discovery iterator so shard/replay resources are released. Preserve the original failure when cleanup also fails, and report cleanup problems honestly; do not claim deletion if it failed. Add small fault-injection tests for partial open, failed cleanup after otherwise successful processing, and early upstream close. Keep the implementation simple and platform-safe on Windows.
