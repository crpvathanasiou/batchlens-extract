## Human manual acceptance checklist

Ask the human operator to perform this exact sequence in the running local workspace:

1. Select the prepared approved document.
2. Confirm the reviewed HTML is visible on the left.
3. Click **Classify pages** once.
4. Observe truthful page progress and that conflicting actions are disabled while classification is running.
5. When terminal, inspect several displayed labels/evidence items and each page’s eligibility/exclusion result.
6. Confirm any visible `needs_review`, incomplete, failed, or interrupted status is informational and does not appear as classifier approval.
7. Click **Extract All**.
8. Observe truthful lexical queued/running/publishing/completed or failure status, distinct from classification status.
9. If extraction completes, open the resulting run and confirm:
   - classification labels are identified as that run’s immutable snapshot;
   - lexical findings remain available;
   - classification labels are informational;
   - existing Save, Download TXT, and **Approve extraction result** behavior still works.
10. In the fresh acceptance data directory only, make one harmless Stage 3 review edit, Save it, then use the single final **Approve extraction result** action.

Expected alternate outcome:

- If every page is conservatively excluded, the exact no-eligible-pages message is a successful result. Do not submit an empty Stage 2 run and do not claim that lexical findings or Stage 3 approval were manually tested in that run.

Do not force invalid evidence or fabricate a classifier failure in the live run. Those behaviors remain automated-test-verified unless naturally observed.
